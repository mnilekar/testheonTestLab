Checked out: 2026-09-28

## Scope

1. Build `/practice/components/frames-and-windows/` with single, form, nested, multiple and dynamic same-origin frames plus deterministic tab, popup, sign-in and parent-update flows.
2. Build `/practice/components/files/` with safe uploads, previews, rejection, progress and deterministic PDF, CSV and text downloads.
3. Enforce server-side upload safety with MIME and extension validation, content sniffing, private random storage, execution prevention, no raw serving, expiration and per-session quotas.
4. Build `/practice/components/drag-and-drop/` with HTML5 and pointer interactions, sortable and keyboard reordering, a shared file dropzone and API-backed Kanban persistence.
5. Build `/practice/components/browser-context/` with cookie, storage, permission, location, offline and responsive-state fixtures.
6. Add the requested Playwright TypeScript examples, fixture registrations, local and hosted tests, protected/noindex staging deployment, R4 production evidence and the required checkpoint report.

The permanent rules in `AGENTS.md` and `docs/CHUNK-00-GROUND-RULES.md` remain authoritative. Production WordPress stays untouched.
