## Executive summary

Google Trends strongly supports retaining **`playwright python`** as PW-04's primary keyword. In the required core comparison, `playwright python` and `python playwright` were effectively tied in every measured market and window. `playwright python` is preferable editorially because it follows the product-first wording used by the Testheon cluster and preserves clean ownership.

The largest verified supporting intent is Python-specific installation: `playwright python install` and `python playwright install` each averaged 8 versus the anchor's 48 in Worldwide 12-month data. API wording (`playwright python api` / `playwright api python`, 4), locator singular wording (2), and `pip install playwright` (2) were smaller but visible. Tutorial, pytest, framework, fixtures, sync/async, authentication, and automation-modifier variants were weak or below reportable resolution in anchored comparisons.

Python was the strongest measured Playwright language path: WW 12-month averages were Python 48, TypeScript 8, Java 8, JavaScript 7, and C# 3. Selenium remains strategically important: in WW 12 months Playwright Python (47) slightly exceeded Selenium Python (43), but over five years Selenium Python (57) remained far above Playwright Python (15). In India, Selenium Python (51) exceeded Playwright Python (38); in the US, Playwright Python (35) exceeded Selenium Python (29).

The 12-month time series showed a material rise from the high 20s in late 2025 to two peaks of 100 in May and June 2026, followed by a decline in the incomplete August 2026 tail. This supports strong 2026 interest, but the recent deceleration means it should not be described as continuously accelerating.

## Methodology and limitations

- The requested Google Trends MCP was unavailable. With user approval, research used the public Google Trends Explore interface through browser automation.
- All comparisons used **Search Terms**, not Topics, with Web Search and all categories.
- Google Trends reports normalized relative interest from 0–100. It is **not monthly search volume**. A value of 100 is peak relative interest within the selected query, geography, time, and comparison context. A value of 0 can mean insufficient reportable data, not no searches.
- `playwright python` was retained as the anchor in every ancillary batch.
- Values from separate batches were not ranked as if they shared a scale. Cross-batch conclusions use ratios to the common anchor and are approximate.
- The browser encountered a reCAPTCHA, the user manually cleared it, and research resumed. A second reCAPTCHA occurred during the country-ranking check. Per user instruction, all further access stopped immediately.
- Consequently, top/rising related-query retrieval, complete country concentration (including direct US and India concentration), and a few five-year rows that failed to render remain incomplete. No substitute values were invented.
- The final week beginning 2026-08-30 was incomplete and is not used as evidence of underlying demand.
